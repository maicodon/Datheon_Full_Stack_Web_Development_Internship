A modern, responsive personal portfolio website showcasing my professional profile, technical capabilities, selected projects, and digital solutions.

#Overview#
This project is my personal portfolio website, developed to establish a professional online presence and showcase my skills, experience, and practical work.

The website provides recruiters, potential employers, collaborators, and clients with an overview of my background, technical competencies, projects, and contact information.

Key Features
- Responsive layout for desktop, tablet, and mobile devices.
- Dark and light mode functionality.
- Interactive navigation and mobile menu.
- Projects showcase with project details.
- Interactive project modal.
- Scroll-based reveal animations.
- Active navigation state.
- Contact form with client-side validation.
- Web3Forms integration for contact message delivery.
- Professional profile and résumé presentation.

Contact Form Configuration
The contact form is designed to use Web3Forms for message delivery.

To configure the service:
1. Visit https://web3forms.com/.
2. Generate an access key.
3. Add the access key to the form's hidden `access_key` input.
4. Submit a test message to verify delivery.

Never publish private credentials or sensitive environment variables in the repository.
